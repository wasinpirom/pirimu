PiriMU - เว็บบราวเซอร์สำหรับสายมู โดย ดร.วศิน ภิรมย์
https://pirimu.com

วิธีติดตั้ง (Windows 10 / 11)
1. ติดตั้ง Python 3.12 จาก https://www.python.org/downloads/
   ตอนติดตั้งให้ติ๊ก "Add python.exe to PATH"
2. ดับเบิลคลิก install.bat
   ถ้าขึ้นหน้าจอสีน้ำเงิน "Windows protected your PC"
   ให้กด More info แล้วกด Run anyway
3. รอจนเสร็จ (ครั้งแรกใช้เวลา 3-10 นาที)
4. เปิดใช้งานจากไอคอน PiriMU บน Desktop

อัปเดตเวอร์ชันใหม่: ดาวน์โหลดไฟล์ใหม่ แตกไฟล์ทับโฟลเดอร์เดิม แล้วดับเบิลคลิก install.bat อีกครั้ง
(ธีม บุ๊กมาร์ก และวันเกิดที่ตั้งไว้ยังอยู่ครบ)

ถอนการติดตั้ง: ลบโฟลเดอร์นี้ ลบไอคอนบน Desktop
และถ้าต้องการลบข้อมูลด้วย ให้ลบโฟลเดอร์ .pirimu ใน C:\Users\ชื่อคุณ\
