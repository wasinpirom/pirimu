PiriMU - เว็บบราวเซอร์สำหรับสายมู โดย ดร.วศิน ภิรมย์
https://pirimu.com

วิธีติดตั้ง (macOS)
1. ติดตั้ง Python 3.12 จาก https://www.python.org/downloads/ (ถ้ายังไม่มี)
2. คลิกขวาที่ install.command แล้วเลือก Open (เปิด) จากนั้นกด Open อีกครั้ง
   (ถ้ากดเปิดแบบดับเบิลคลิกปกติ Mac จะบล็อกไฟล์จากอินเทอร์เน็ต)
   ถ้ายังเปิดไม่ได้: ไปที่ System Settings > Privacy & Security แล้วกด Open Anyway
   หรือเปิดแอป Terminal แล้วพิมพ์
     bash ~/Downloads/PiriMU-Mac/install.command
3. รอจนเสร็จ (ครั้งแรกใช้เวลา 3-10 นาที)
4. เปิด PiriMU จาก Launchpad หรือ Spotlight (⌘+Space แล้วพิมพ์ PiriMU)

อัปเดตเวอร์ชันใหม่: ดาวน์โหลดไฟล์ใหม่ แตกไฟล์ทับโฟลเดอร์เดิม แล้วเปิด install.command อีกครั้ง

ถอนการติดตั้ง: ลบโฟลเดอร์นี้ ลบ PiriMU ใน ~/Applications
และถ้าต้องการลบข้อมูลด้วย ให้ลบโฟลเดอร์ ~/.pirimu
