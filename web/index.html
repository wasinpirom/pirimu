ดาวน์โหลดและติดตั้ง

ใช้ได้ทั้ง Windows 10/11 และ macOS ไฟล์ขนาดประมาณ 150–200 MB

💌 รับข่าวเวอร์ชันใหม่และเคล็ดลับสายมูทางอีเมล

ไม่บังคับ ดาวน์โหลดได้เลยโดยไม่ต้องกรอก

วิธีที่ 1 แนะนำ: ตัวติดตั้ง ดับเบิลคลิกจบ

ไม่ต้องลง Python ไม่ต้องพิมพ์คำสั่ง ติดตั้งเหมือนโปรแกรมทั่วไป

แนะนำสำหรับเครื่องนี้

🪟 Windows 10 / 11

ดาวน์โหลด PiriMU-Setup.exe
  1. ดับเบิลคลิกไฟล์ PiriMU-Setup.exe ที่ดาวน์โหลดมา
  2. ถ้าขึ้นหน้าจอสีน้ำเงิน “Windows protected your PC” ให้กด More info แล้วกด Run anyway (ขึ้นเพราะโปรแกรมใหม่ยังไม่ได้ซื้อใบรับรองจาก Microsoft)
  3. กด ถัดไป รอสักครู่ แล้วกด เสร็จสิ้น (ไม่ต้องใช้สิทธิ์ admin)
  4. PiriMU จะเปิดขึ้นมาเอง ครั้งต่อไปเปิดจากไอคอนบน Desktop หรือ Start Menu

ถอนการติดตั้ง: Settings → Apps → PiriMU → Uninstall

แนะนำสำหรับเครื่องนี้

🍎 macOS (ชิป Apple M1 ขึ้นไป)

ดาวน์โหลด PiriMU สำหรับ Mac
  1. ดับเบิลคลิกไฟล์ PiriMU-Mac-App.zip ที่ดาวน์โหลดมา จะได้แอป PiriMU
  2. ลาก PiriMU ไปวางในโฟลเดอร์ Applications
  3. เปิดครั้งแรก: ใน Applications ให้คลิกขวาที่ PiriMU เลือก Open แล้วกด Open อีกครั้ง
  4. ถ้า Mac ไม่ยอมเปิด ให้เปิดแอป Terminal วางคำสั่งนี้แล้วกด Enter (ทำครั้งเดียว)
    xattr -cr /Applications/PiriMU.app

Mac รุ่นเก่าชิป Intel ให้ใช้วิธีที่ 2

วิธีที่ 2 สำรอง: วางคำสั่งเดียว

ใช้เมื่อวิธีที่ 1 ใช้ไม่ได้ หรือใช้ Mac ชิป Intel ระบบจะดาวน์โหลด ติดตั้ง และสร้างไอคอนให้เอง บน Windows ถ้ายังไม่มี Python ระบบจะติดตั้งให้ด้วย

🪟 Windows

  1. กดปุ่ม Start พิมพ์ PowerShell แล้วกดเปิด
  2. คัดลอกคำสั่งนี้ไปวาง แล้วกด Enter
    irm https://pirimu.com/install.ps1 | iex
  3. รอจนขึ้นว่าติดตั้งเสร็จ PiriMU จะเปิดขึ้นมาเอง ครั้งต่อไปเปิดจากไอคอนบน Desktop หรือ Start Menu

🍎 macOS

  1. กด ⌘ Space พิมพ์ Terminal แล้วกด Enter
  2. คัดลอกคำสั่งนี้ไปวาง แล้วกด Enter
    curl -fsSL https://pirimu.com/install.sh | bash
  3. ถ้ามีหน้าต่างให้ติดตั้ง Command Line Tools ให้กด Install รอจนเสร็จ แล้ววางคำสั่งเดิมอีกครั้ง
  4. เมื่อเสร็จ PiriMU จะเปิดขึ้นมาเอง ครั้งต่อไปเปิดจาก Launchpad หรือ Spotlight

วิธีที่ 3 สำหรับนักพัฒนา: ไฟล์ zip แบบใช้ Python

🪟 Windows 10 / 11

  1. ติดตั้ง Python 3.12 หน้าแรกของตัวติดตั้งให้ ติ๊กช่อง “Add python.exe to PATH” แล้วกด Install Now
  2. ดาวน์โหลด PiriMU-Windows.zip
  3. คลิกขวาที่ไฟล์ zip เลือก Extract All แล้วย้ายโฟลเดอร์ไปไว้ที่ถาวร เช่น Documents
  4. ดับเบิลคลิก install.bat ถ้าขึ้นหน้าจอสีน้ำเงิน “Windows protected your PC” ให้กด More info แล้วกด Run anyway
  5. รอจนขึ้นว่าติดตั้งเสร็จ แล้วเปิดใช้จากไอคอน PiriMU บน Desktop
ดาวน์โหลด zip สำหรับ Windows

🍎 macOS

  1. ติดตั้ง Python 3.12 (ไฟล์ macOS installer กด Continue ไปจนจบ)
  2. ดาวน์โหลด PiriMU-Mac.zip แล้วดับเบิลคลิกเพื่อแตกไฟล์
  3. คลิกขวาที่ install.command เลือก Open แล้วกด Open อีกครั้ง ถ้ายังเปิดไม่ได้ ไปที่ System Settings → Privacy & Security แล้วกด Open Anyway
  4. รอจนขึ้นว่าติดตั้งเสร็จ PiriMU จะเปิดขึ้นมาเอง
  5. ครั้งต่อไปเปิดจาก Launchpad หรือกด ⌘ Space แล้วพิมพ์ PiriMU
ดาวน์โหลด zip สำหรับ Mac

อัปเดตเวอร์ชันใหม่

เมื่อมีเวอร์ชันใหม่ ปุ่ม “🆕 มีเวอร์ชันใหม่” จะขึ้นที่มุมล่างของ PiriMU ให้ดาวน์โหลดตัวติดตั้งใหม่แล้วติดตั้งทับได้เลย ธีม บุ๊กมาร์ก และวันเกิดที่ตั้งไว้จะยังอยู่ครบ

มีอะไรใหม่

    คำถามที่พบบ่อย

    ต้องลง Python ไหม

    ไม่ต้อง ถ้าใช้ตัวติดตั้งในวิธีที่ 1 ทุกอย่างรวมมาในไฟล์เดียวแล้ว PiriMU ใช้เครื่องยนต์ Chromium ตัวเดียวกับ Chrome

    ปลอดภัยไหม ทำไม Windows หรือ Mac ถึงเตือน

    ระบบเตือนเพราะไฟล์ไม่ได้ซื้อใบรับรองจาก Microsoft หรือ Apple ไม่ได้แปลว่ามีอันตราย โค้ดทั้งหมดเปิดให้ดูได้ที่ GitHub

    เว็บนี้เก็บข้อมูลหรือใช้คุกกี้ไหม

    ไม่เก็บและไม่ใช้คุกกี้ ไม่มีระบบติดตามสถิติ ไม่ต้องสมัครสมาชิก ดาวน์โหลดได้โดยไม่ต้องกรอกอะไร อ่านรายละเอียดได้ที่ นโยบายความเป็นส่วนตัว

    แจ้งปัญหาได้ที่ ดร.วศิน ภิรมย์ Line OA: @wasin

    วันเกิดที่ใส่ไปถูกส่งไปที่ไหน

    ไม่ถูกส่งไปที่ไหนเลย วันเกิด ธีม บุ๊กมาร์ก และประวัติเก็บไว้ในเครื่องคุณเท่านั้น หมอดูปิริคำนวณในเครื่องทั้งหมด

    ติดตั้งแล้วขึ้นว่าไม่พบ Python

    Windows: ติดตั้ง Python ใหม่แล้วติ๊ก “Add python.exe to PATH” จากนั้นรีสตาร์ตเครื่องแล้วลองอีกครั้ง Mac: ติดตั้ง Python จาก python.org แล้วเปิด install.command ใหม่

    ดาวน์โหลดค้าง หรือติดตั้งไม่สำเร็จ

    ตรวจสอบอินเทอร์เน็ต แล้วเปิด install อีกครั้ง โปรแกรมจะทำต่อจากจุดเดิม ถ้าใช้เครือข่ายที่ทำงานหรือมหาวิทยาลัยที่บล็อกการดาวน์โหลด ลองใช้เน็ตบ้านหรือแชร์เน็ตมือถือ ถ้ายังไม่ได้ แคปหน้าจอแล้วแจ้งที่ ดร.วศิน ภิรมย์ Line OA: @wasin

    ถอนการติดตั้งอย่างไร

    ลบโฟลเดอร์ PiriMU และไอคอนบน Desktop (Windows) หรือ PiriMU ใน Applications ของโฮม (Mac) ถ้าต้องการลบข้อมูลด้วย ให้ลบโฟลเดอร์ .pirimu ในโฟลเดอร์ผู้ใช้

    ดูดวงแม่นไหม

    หมอดูปิริทำขึ้นเพื่อความบันเทิงและเป็นกำลังใจในแต่ละวัน โปรดใช้วิจารณญาณในการตัดสินใจเรื่องสำคัญ
